UsageMax collects aggregate usage from the coding agents you already run. Link each computer that holds agent history to see token counts, model mix, sessions, and estimated API-equivalent cost in one workspace.

## Get started

- [Connect your first computer](/quickstart) and verify the first sync.
- [Find your coding agent](/supported-agents) and check which history the collector can see.
- [Set up scheduled sync](/cli#schedule-sync) if you want the workspace to stay current.
- [Understand your usage totals](/accounting), including cached tokens and estimated cost.

## Build with UsageMax

Use the [API](/api) for public usage data, [telemetry ingestion](/telemetry) for your own runtimes, or [MCP](/mcp) to connect an AI client. For shared projects and budgets, see [Team workspaces](/teams).
