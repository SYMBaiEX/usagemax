## Connect over Streamable HTTP

Add this MCP server to a compatible client. The surrounding configuration varies by client.

```json
{
  "mcpServers": {
    "usagemax": {
      "type": "http",
      "url": "https://usagemax.com/mcp"
    }
  }
}
```

Use the server to look up published profiles, leaderboard results, public stats, and documentation. It exposes public, read-only projections.
