September 15, 2026. Direct visual review, not a frontend skill template.

No third-party artwork, proprietary typefaces, mascots, photographs, testimonials, or customer logos were copied.

## Implemented direction

UsageMax is an instrument for understanding AI work. Its original physical counter is made from CSS geometry, uses real network totals, and switches between tokens, sessions, and cost. It is an interactive visualization, not a claim to sell hardware or a simulation of live usage.

An ink-blue stage and orange display anchor the home page. A small overlapping network readout leads into actual public profiles. A terminal scene explains setup; the team section uses a quieter green identity. No announcement banner or decorative page separators.

Profiles retain their real chart behavior and data definitions, with a dark token summary and unboxed secondary metrics. Enterprise has a distinct green introduction. Documentation uses a compact reference layout. Trust and legal pages prioritize readable prose; account controls retain existing authorization boundaries.

## Performance and correctness boundaries

- No added runtime dependencies, WebGL, video, raster hero downloads, animation library, polling, or animation frames.
- One finite 900ms counter entrance; 300ms digit changes only when values or the selected metric change. Reduced-motion users receive no animation.
- Existing bounded Convex subscriptions preserved: two on home; one bounded snapshot on profiles. No synthetic counters, random activity, or fake profiles.
- Costs remain labeled estimates or provider-reported amounts, not invoices. Unknown totals remain unknown rather than zero. Metric-specific leaderboard periods remain intact.
- Physical display work, collection, authentication, authorization, and ingestion are out of scope for this visual pass.
- Only two self-hosted font families, down from three. Charts remain lazy-loaded and do not animate the data itself.
