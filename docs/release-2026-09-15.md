# UsageMax / Studio and Signal

## Art direction

- **Studio (light):** cream paper, navy editorial hero, warm physical counter, rounded Facehash identities, studio-lit CTA sculpture.
- **Signal (dark):** near-black canvas, headline over a full-width instrument bench, graphite counter, compact square controls and identities, re-composed profile cover, orange-lit CTA sculpture.
- Both variants use the same Convex subscriptions and underlying records. This is a user-selectable design variant, not an analytics experiment or separate data store.
- Visual research: [Cossistant](https://cossistant.com/) for near-black contrast, small technical type, compact controls and ambient source-code texture. No Cossistant source code or assets copied.
- [Facehash](https://www.facehash.dev/) 0.1.0 generates local deterministic identities from public handles, not mutable display names. MIT dependency; no external avatar service, blinking, or mouse tracking.

## Performance and accessibility

- CSS-transform-only ambient code, paused when off-screen, when the document is hidden, when the user pauses it, or under reduced-motion preferences. No animation timers, canvas loops, telemetry polling, or new scanning.
- Ambient snippets are decorative source-code illustrations, hidden from assistive technology; they are not represented as real logs. The readable hero readout uses actual network totals.
- Theme choice persists locally, defaults to the device preference, and is initialized before first paint. Blocked storage falls back safely. Footer offers an explicit return to device theme.
- Counter glyphs size against each reel's actual container width; triple-digit tokens, sessions, and compact currency remain visible. Accessible full metric value remains on the readout.
- Two generated CTA assets are approximately 55 KB each, lazy-loaded with responsive sizing. Avatar geometry changes with the theme.

- CLI remains dependency-only/current; no new daemon behavior or npm publish is part of this design release.
